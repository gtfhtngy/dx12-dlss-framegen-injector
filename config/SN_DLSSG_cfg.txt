# Scarlet Nexus - DLSS Frame Generation (Streamline) config
# fg        : 1 = on, 0 = off
# mult      : 2 = 2x (1 generated frame). 3/4 need an RTX 50 series card (clamped automatically)
# stage     : 0 = pass-through, 1 = only init Streamline + log feature support, 2 = full frame generation
# log       : 1 = write SN_DLSSG_log.txt + Streamline log files next to the exe
# hudless   : 1 = experimental HUD-less capture (copy of the back buffer right before the Nth draw to it)
# hudlessdraw: N for hudless=1 (try 2,3,4,... until UI artifacts disappear; see log 'bbdraws')
# renderw/renderh/tol : internal render resolution of the game (depth/velocity buffers) +- tolerance
# camauto   : 1 = automatically find the camera matrices in the UE4 view buffer when the offsets below do not fit this game (look for 'cam-scan: LOCKED' in the log)
# projoff / noaaoff : float index of ViewToClip / ViewToClipNoAA (116 / 132 for Scarlet Nexus)
# mvoff     : float index of ClipToPrevClip inside the UE4 view uniform buffer (492 for Scarlet Nexus)
# warmup    : frames before frame generation is switched on
# reflexsleep : 1 = also call slReflexSleep every frame, baseFpsLimit = cap for the BASE fps (0 = none)
# fgminfps : >0 = pause frame generation while the BASE fps is below this value (busy scenes), resume at value+8 (0 = never)
# reflexplace : 1 = Reflex sleep/markers at the start of the game frame (experimental)
# log       : 1 = normal log, 2 = + verbose Streamline log (debug only, slow)
# fgdelay : frames the camera must be valid in a row before FG is switched on again (default 30) - avoids on/off flapping while a level loads
# bufmaxmb : max MB of upload buffers the camera tracker may keep alive (default 192)
# sldir     : folder containing sl.interposer.dll, sl.common.dll, sl.dlss_g.dll, sl.reflex.dll, sl.pcl.dll, nvngx_dlssg.dll (empty = exe folder)
