# Scarlet Nexus - DLSS Frame Generation (Streamline) config
# fg        : 1 = on, 0 = off
# mult      : 2 = 2x (1 generated frame). 3/4 need an RTX 50 series card (clamped automatically)
# stage     : 0 = pass-through, 1 = only init Streamline + log feature support, 2 = full frame generation
# log       : 1 = write SN_DLSSG_log.txt + Streamline log files next to the exe
# hudless   : 1 = experimental HUD-less capture (copy of the back buffer right before the Nth draw to it)
# hudlessdraw: N for hudless=1 (try 2,3,4,... until UI artifacts disappear; see log 'bbdraws')
# renderw/renderh/tol : internal render resolution of the game (depth/velocity buffers) +- tolerance. renderw=0 renderh=0 = AUTO (UE5 / TSR / dynamic screen percentage)
# velfallback : v19 1 = if no velocity buffer is found, run FG with camera-only motion vectors (dummy zero velocity); velwait = frames to wait first
# velfmt    : v19 extra DXGI format number accepted as velocity target (34=R16G16_FLOAT 37=R16G16_SNORM 16=R32G32_FLOAT 15=R32G32_TYPELESS, 0=none) - see the census lines in the log
# viewrect : v20 1 = use the real view rect (viewport on the depth buffer) instead of the whole depth/velocity buffer (fixes the stale band at the bottom/right edge with dynamic resolution), 0 = off
# c2pauto : v21 1 = switch ClipToPrevClip candidate if the locked one never moves while another does (see c2p-monitor in the log), 0 = off
# c2pidx    : v18 (UE5) which identity-like matrix after ViewToClipNoAA is ClipToPrevClip (0 = first). Only used by the automatic camera scan
# camauto   : 1 = automatically find the camera matrices in the UE4 view buffer when the offsets below do not fit this game (look for 'cam-scan: LOCKED' in the log)
# projoff / noaaoff : float index of ViewToClip / ViewToClipNoAA (116 / 132 for Scarlet Nexus)
# mvoff     : float index of ClipToPrevClip inside the UE4 view uniform buffer (492 for Scarlet Nexus)
# warmup    : frames before frame generation is switched on
# reflexsleep : 1 = also call slReflexSleep every frame, baseFpsLimit = cap for the BASE fps (0 = none)
# fgminfps : >0 = pause frame generation while the BASE fps is below this value (busy scenes), resume at value+8 (0 = never)
# reflexplace : 1 = Reflex sleep/markers at the start of the game frame (experimental)
# log       : 1 = normal log, 2 = + verbose Streamline log (debug only, slow)
# fgdelay : frames the camera must be valid in a row before FG is switched on again (default 30) - avoids on/off flapping while a level loads
# camstale : frames without a fresh camera before FG is switched off (default 30; v15 used 6 -> FG flapped on short hitches)
# bufmaxmb : max MB of upload buffers the camera tracker may keep alive (default 192)
# psoretry : 1 = (v17) if the GAME fails to create a pipeline state (E_INVALIDARG), write the details to the log and retry once without the cached blob; 0 = off
# cutdetect : 1 = detect camera cuts / FOV jumps (Special Shots, cutscenes) and reset the DLSS-G history (v23: FG is NO LONGER switched off for this - every FG off/on = 100+ ms hitch), 0 = off
# cutthresh : v23 ClipToPrevClip deviation x100 that counts as a cut (default 120 = 1.20; v22 used 25 and fired on every fast camera turn)
# cutfov    : v23 projection (FOV) change in percent that counts as a cut (default 8; v22 used 2)
# sldir     : folder containing sl.interposer.dll, sl.common.dll, sl.dlss_g.dll, sl.reflex.dll, sl.pcl.dll, nvngx_dlssg.dll (empty = exe folder)
# camhold   : v24 1 = if the camera view buffer is lost while FG is running (level load, streaming), KEEP FG on (last projection + identity ClipToPrevClip = optical flow only) instead of switching it off for the rest of the session
# camholdmax: v24 max frames to hold without a camera before FG is switched off (default 7200)
# camrescan : v24 frames without a camera before the tracker re-scans with relaxed checks (aspect check relaxed, scan even though offsets were locked). 0 = never
# reflexalways: v24 1 = slReflexSleep also while FG is off/paused/warming up (v23 behaviour; cost ~20 ms per frame at the 9 fps start of the game). 0 = only when FG runs
# fgminbackoff: v24 1 = every FG pause (fgminfps) doubles the number of good frames needed before FG resumes (stops on/off flapping, every switch = 100+ ms hitch)
